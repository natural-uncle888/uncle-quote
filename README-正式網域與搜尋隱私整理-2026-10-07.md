# 自然大叔｜線上報價單｜正式網域與搜尋隱私整理

日期：2026-10-07
正式網址：https://quote.naturaluncle.com/

本次修改：
- 將報價單 Open Graph 網址改為正式網域 quote.naturaluncle.com。
- 新增 canonical 指向正式網域。
- 將「自然大叔官方網站」舊 netlify.app 連結改為 https://naturaluncle.com/。
- 將管理頁 file:// 模式的舊 Netlify fallback 網址改為正式網域。
- 報價系統與管理頁加入 noindex / nofollow / noarchive。
- Netlify 全站加入 X-Robots-Tag，避免顧客報價內容與管理頁被 Google 收錄。
- 新增 robots.txt，阻擋管理、API 與顧客分享路徑的搜尋引擎爬取。
- 頁尾版權年份更新為 2026。

注意：
此系統屬於報價與顧客確認工具，可能含姓名、電話、地址、金額等資料，因此刻意不建立 sitemap，也不建議讓此子網域出現在 Google 搜尋結果。
